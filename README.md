# 🛡️ Phishing Simulation & Security Training Platform

A sandbox platform for conducting **controlled phishing simulations and employee security awareness training**.

The project allows administrators to create phishing simulations, manage employees, track their interactions, provide training, conduct quizzes, and generate reports.

> ⚠️ This platform is intended only for authorized security awareness testing and controlled environments.

## ✨ Features

* 🔐 Administrator login and management
* 👥 Employee management
* 🎣 Phishing simulation campaigns
* 📧 Simulated phishing emails
* 🖥️ Simulated login/landing pages
* 📊 Campaign tracking and analytics
* 🎓 Employee security training
* 📝 Security awareness quizzes
* ⚠️ Employee risk assessment
* 📈 Dashboards and reports
* 📄 PDF and CSV exports
* 📝 Audit logs
